# Aether Kart Odyssey — playable build

This repository contains **only the built artifact**. The source is private.

Play: https://jaywilliams0507-pixel.github.io/aether-kart-play/

An open-world kart racer that runs entirely in a browser tab. Everything —
terrain, karts, sky, audio, fonts — is generated procedurally in code at runtime.
There are zero external asset files.

**This is an unfinished prototype under active playtesting.** Known gaps are
listed in the playtest packet; the short version is that over-drifting has no
penalty yet, AI difficulty is not monotonic, and performance has never been
verified on a real phone.
